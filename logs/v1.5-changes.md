# System v1.5 — change log

## Context

Per user instruction: _"prune it — anything requiring Gemini to be pruned, any
code not used to be pruned, and remember all changes to be logged."_

The Gemini integration had already been disabled in production in v1.2 (the
console page rendered `null`, the API routes returned 410/503 stubs), but the
underlying code — the full Gemini API client, the AI trade-selection/research
layer, the debate engine, the Gemini test batteries, and the Gemini research
scripts — was still shipping. This release removes all of it, plus the dead
code that only existed to serve it.

## What was pruned

### 1. The entire Gemini/AI layer (`src/lib/ai/` — 10 files)

- `src/lib/ai/gemini.api.ts` — the direct Google Gemini client
- `src/lib/ai/console.ts` — Gemini console server helpers
- `src/lib/ai/evaluate.ts`, `research.ts` — Gemini evaluation/research
- `src/lib/ai/select/` — `candidates.ts`, `evaluate.ts`, `evidence.ts`,
  `news.ts`, `selector.ts`, `windows.ts` (the Gemini trade-selection pipeline)

These were imported only by the Gemini scripts and Gemini tests (both pruned).
No production code referenced them.

### 2. Gemini-only server/route/page plumbing

- `src/lib/ai-debate.server.ts` — Gemini↔Gemini "debate" engine (0 importers)
- `src/lib/citation-verify.ts` — citation verification for Gemini output (0 importers)
- `src/lib/economic-calendar.ts` — client helper for the Finnhub calendar
  (its only consumer was the Gemini news layer; 0 importers)
- `src/pages/GeminiConsole.tsx` — stub page (rendered `null`)
- `src/pages/Analysis.tsx` — the `[DEPRECATED]` V1 "Dual-Model" AI-debate page
  (its only function was streaming a Gemini debate from `/api/analysis`)
- `src/routes/gemini-console.tsx` — 410 removal stub
- `src/routes/api/gemini-console.ts` — 410 removal stub
- `src/routes/api/analysis.ts` — 503 removal stub (Gemini debate endpoint)
- `src/routes/api/economic-calendar.ts` — live Finnhub calendar endpoint whose
  only consumer was the removed Gemini console
- `src/routes/analysis.v1.tsx` — the deprecated V1 route
- `prompts/trade-selector.system.md` — Gemini system prompt

### 3. Gemini research scripts (`scripts/`)

Two generations of the same tooling, all removed:

- `.ts` set: `gemini-report.ts`, `gemini-research.ts`, `gemini-select.ts`
- `.mjs` set: `gemini-prompt-sub-eval.mjs`, `gemini-prompt-substitute-eval.mjs`,
  `gemini-trade-select-experiment.mjs`, `run-gemini-prompt-sub.mjs`
- `_gemini-auth-probe.mjs` — an auth probe sketch left in-tree

### 4. Gemini test batteries (`tests/`)

- `gemini-console.test.mjs`, `gemini-phase2.test.mjs`, `gemini-research.test.mjs`,
  `gemini-select.test.mjs` (44 tests removed).

### 5. The backtester's "debate" AI stage

`src/lib/backtest/ai.ts` had two stages: a non-Gemini **verifier** and a Gemini
**debate** (`runDebate`, which posted to the already-removed `/api/analysis`).
Pruned the debate stage:

- Removed `runDebate` + `DebateOutcome` from `backtest/ai.ts`
- `AiStage` narrowed from `"off" | "verifier" | "debate" | "both"` to
  `"off" | "verifier"`
- Removed the debate block, the `debate`/`both` selector options, and the
  "Gemini ↔ GPT debate" labels from `src/pages/Backtest.tsx`
- Removed the "Gemini console" nav link (and the now-unused `Bot` icon import)
  from the backtester header

### 6. Dead provider-union member

`src/lib/verifier.server.ts` declared `provider: "gemini" | ...`, but the
verifier's attempt list only ever produced `lovable` / `openrouter` / `nvidia`.
Removed the dead `"gemini"` member.

### 7. Env / comments

- `.env.example` — removed `FINNHUB_API_KEY` (its only consumer, the Finnhub
  calendar, is gone). Kept Twelve Data + the Lovable/OpenRouter/NVIDIA keys.
- `src/routes/api/market-data.ts` — removed the now-stale "Finnhub is reserved
  for news" references.
- `src/routeTree.gen.ts` — regenerated by the build (drops the removed routes).

## Deliberately kept (not Gemini-dependent)

- **The V2 verifier/picker** (`src/lib/verifier.server.ts`,
  `src/lib/verifier.functions.ts`, `src/components/verifier-panel.tsx`, and the
  backtester's verifier stage). It uses the Lovable / OpenRouter / NVIDIA
  gateways — **not** the Gemini API or `GEMINI_API_KEY`. This is the documented
  "non-Gemini verifier" path. Note: its Lovable provider names the model
  `google/gemini-2.5-flash`, but that is reached via Lovable's OpenAI-compatible
  gateway with `LOVABLE_API_KEY`, so it does not "require Gemini" in the
  pruned sense; left intact.
- **Lovable error reporting / error capture / error page** — infrastructure,
  not Gemini.
- **`artifacts/strategy-research/gemini-*`** — historical research _data_
  (JSON/JSONL/MD), not code. Preserved as documentation of prior research;
  delete on request if not wanted.
- **`server-env.ts`** — still used by the market-data route and the verifier.
- The Finnhub "never a candle provider" regression pin in
  `tests/server-env.test.mjs` — still a meaningful guard against a future
  Finnhub candle path.
