## Filter C rule (unchanged implementation)

Reject PASS candidates when **all** of:

- counter-trend (local structure trend opposes trade side)
- ATR percentile ≥ 95%

Causal details (unchanged in `src/lib/analyzer/regime-filters.ts`):

- prior 50-bar ATR reference window `[i-50, i)`
- full 50-bar history required (else do not reject)
- current ATR excluded from the reference set
- entry-time data only; no look-ahead
- rejected trades do **not** consume the strategy/day/side slot
