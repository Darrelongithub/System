# System v1.4 — change log

## Context

An independent audit (2026-09-08, see `AUDIT-ARENA-2026-09-08.md`) found the repo's
own certification suite red: `npm test` was **89 passed / 5 failed**, and the
"golden regression" lock no longer reproduced the frozen golden. This release
repairs that lock and closes the smaller hygiene gaps found in the same pass.

## Root cause of the broken golden lock (two deliberate changes, never re-based)

The frozen golden artifacts (`golden-trades.json` 2384 trades, `golden-summary.json`
R 507.83) were generated **before** two production changes that both moved trade counts:

| Change                                                              | Version | Effect on baseline                                           | Guarded by a flag?           |
| ------------------------------------------------------------------- | ------- | ------------------------------------------------------------ | ---------------------------- |
| A2 consume-after-RR fix (`consume` only after spread/RR validation) | v1.2    | **+3** trades (2× macd-cross + 1× dual-thrust on 2025-12-26) | No                           |
| Filter C enabled by default (`enableFilterC ?? true`)               | v1.3    | **−64** trades                                               | Yes (`enableFilterC: false`) |

Net: production default now yields **2323** resolved trades, not 2384. Neither change
was followed by a golden re-baseline, so the row-for-row golden gate, `test:golden`,
and the parity/G1 accounting tests all began failing — and the "CERTIFIED" claims in
`AUDIT-2026-08-30.md` went stale.

Verified directly against the baseline (field-exact on the 2384 shared trades):

```
runAnalysis(..., enableFilterC: false)  → 2387 trades  (2384 shared, +3 A2, 0 field mismatches)
runAnalysis(..., default / Filter C on)  → 2323 trades
```

### 2. New: reproducible golden generator (`scripts/generate-golden.mjs`)

The repo previously had **no committed way to regenerate the golden** — it was
produced by an un-committed ad-hoc process (a gap in itself). Added a script that
runs the analyzer with the exact certification options and rewrites the three golden
artifacts. Policy note embedded in the script: do not run it to make a failing test
pass; only a deliberate, documented product change justifies a re-baseline (and must
get its own `logs/` entry).

### 3. Test harness reconciled (hardcoded golden numbers + stale contract test)

- `tests/backtest-analyzer-parity.test.mjs` — 2384→2323, 768→756, 1612→1563.
- `tests/weekend-tail-accounting.test.mjs` — Saturday-tail trigger count 39→37
  (Filter C removed 2 of the old 39 Saturday-tail trades).
- `tests/gemini-console.test.mjs`
  - baseline artifact count 2384→2323 (trade + status assertions).
  - Replaced the "economic-calendar route ↔ console contract" test — it asserted the
    console page consumed `events/byDay`, which was invalidated when the console was
    removed in v1.2. New test pins the **removal stubs** (page renders `null`, page
    route and API route return 410) so a future reinstatement is a deliberate,
    contract-conscious act.

### 4. `.gitignore` added (secret + bloat blindspot)

The repo shipped with **no `.gitignore`**. A naive `git add .` after install would
have committed `node_modules/` (443 packages), a real `.env` (Twelve Data / Gemini /
Finnhub keys), and build/runtime output. Added a `.gitignore` covering `node_modules/`,
`.env*` (keeping `.env.example`), `dist/`/`.output/`/`.wrangler/`/`build/`, `output/`,
and OS/editor noise.

### 5. README corrected

- Artifact list pointed at three files that don't exist
  (`final-validation-report.json`, `robustness-batch2-report.json`,
  `discovery-batch2-report.json`). Replaced with the real artifacts.
- Added the current golden baseline numbers and the Filter C default to the pipeline
  invariants, plus the `npm test` / `generate-golden.mjs` commands.

## Deliberately NOT changed in v1.4 (carried forward as known items)

- `compareHtfDirectionFilter` runs two extra full engine passes per analysis
  (always-equal display table, ~2–3 s main-thread freeze). Perf item only.
- Temporary diagnostics instrumentation (`strategies/diagnostics.ts`) still wired into
  Backtest; self-described as "not meant to ship long-term".
- Two generations of Gemini research scripts under `scripts/` (`.ts` superseded by `.mjs`).
- The removed Gemini Console's server module (`src/lib/ai/**`) still ships and is still
  tested; left fenced as research-only pending a decision on pruning.
- `AVAILABLE_SYMBOLS` advertises crypto/oil symbols the gold-calibrated engine is not
  validated for.
- Approximate ISO-week bucketing in `batchBacktestReports` (cosmetic).

These are correctness-neutral or cosmetic and are documented for a later release.
